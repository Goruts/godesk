# Contributing to Godesk

Thanks for helping. Bug reports, ideas and pull requests are welcome.

## How to contribute

1. Open an issue to describe the bug or the change before large work, so we can agree on the approach.
2. Fork the repository and create a branch from `main`.
3. Keep code, comments and documentation in English, and run `npm test` before you open the pull request.
4. Open a pull request that explains what changes and why.
